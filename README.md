# Meet Poke

Poke is an always-on personal assistant that helps turn intent into action. You can ask Poke to find information, organize plans, work with connected services, draft communications, manage reminders and automations, and build projects—then keep the conversation moving naturally.

Poke is designed to be useful without getting in the way: it gathers the context it needs, takes action when asked, and keeps you informed about what it did and what still needs your attention. Whether you need a quick answer, help coordinating with a team, or support carrying out a multi-step task, Poke is here to help you move from “I should do that” to done.

Start by telling Poke what you want to accomplish—in your own words.
